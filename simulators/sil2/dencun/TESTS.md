# Simulator `sil2/dencun` Test Cases

## Test Suites

### - [SilaDeneb Testnet](suites/base/TESTS.md)
Collection of test vectors that use a ExecutionClient+BeaconNode+ValidatorClient testnet for SilaCancun+SilaDeneb.

### - [SilaDeneb Sync](suites/sync/TESTS.md)
Collection of test vectors that use a ExecutionClient+BeaconNode+ValidatorClient testnet for SilaCancun+SilaDeneb and test syncing of the beacon chain.

### - [SilaDeneb Builder](suites/builder/TESTS.md)

Collection of test vectors that use a ExecutionClient+BeaconNode+ValidatorClient testnet and builder API for SilaCancun+SilaDeneb.


### Clients that require finalization to enable builder
- Lighthouse
- Teku


### - [SilaDeneb Reorg](suites/reorg/TESTS.md)
Collection of test vectors that use a ExecutionClient+BeaconNode+ValidatorClient testnet for SilaCancun+SilaDeneb and test re-orgs of the beacon chain.

### - [SilaDeneb P2P Blobs Gossip](suites/p2p/gossip/blobs/TESTS.md)
Collection of test vectors that verify client behavior under different blob gossiping scenarios.
